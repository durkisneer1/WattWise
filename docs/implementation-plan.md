# Build plan and integration boundary

Repository inspected: initial branch contained README and license only. Work is isolated on codex/wattwise-implementation. User confirmed entire-stack ownership on this branch.

1. Define typed risk/plan contracts and source-linked action bank.
2. Build Axum county selector endpoint and real Open-Meteo retrieval; bounded cache, failure states, provenance.
3. Build deterministic preparation and tightly constrained optional AI selection.
4. Build React location, weather evidence, household questions, priority actions and checklist.
5. Verify Rust behavior, frontend contracts/build and integrated HTTP/browser workflow.
6. Document historical-data gate and honest demo.

Defaults: explicit county selector for Harris (48201), Fort Bend (48157), Montgomery (48339), and Brazoria/Manvel (48039), each with a disclosed reference weather point; hourly rolling 24-hour forecast beginning at next full UTC hour plus unscored 7-day daily outlook. No claim of whole-county weather aggregation. Heuristic index only; probability always null. Upstream forecast issuance unavailable, so issued_at is null and assessment_created_at is separate. Weather fetched_at expires after 30 minutes; cache refresh after 10 minutes per county. Old assessments expire after 30 minutes. No database or household logging.

Deferred: addresses/geocoding, further counties, translation, facility search, battery sizing, accounts and notifications. No data files or validated model initially present. County outage label threshold remains research-only until credible positives/negatives and archive overlap are established. Proposed target for later validation: at least 1,000 customers without power anywhere in the following 24h, daily issue schedule, with temporal evaluation and embargo. This is not the operational index's target.

Integration checkpoints: risk and plan JSON examples generated by backend tests in tests/fixtures; frontend Zod schemas validate the same files. Keep risk.rs, plan.rs and frontend independently reviewable for teammate integration. Do not merge into main automatically.
